# Paper 1 – Hybrid ML–Expert System decision support: prospective evaluation (IMCOM 2027)

Code and results for: S. Mondal, "Toward Intelligent Decision Support: A Machine Learning-Enabled Expert System (ML-ES) Framework for Organizational Productivity Management in Emerging ASEAN Economies — A Malaysian Perspective", IMCOM 2027.

Everything is deterministic (fixed seeds). Python 3.10+; `pip install -r requirements.txt`.

| Folder | Content | Run |
|---|---|---|
| `simulation/` | prospective rolling-origin simulation (5 scenarios x 20 replicates, seeds 20260+r), aggregation, stored raw results | `python run_experiment_prospective.py START COUNT OUTDIR SCENARIO` then `python aggregate_prospective.py DIR` |
| `real_data/` | DOSM quarterly sector-productivity pilot (`qtr.csv`) | `python run_real_data.py qtr.csv` |
| `state_check/` | DOSM annual state-level check (`productivity_state.csv`) | `python run_state_check.py productivity_state.csv 3` (or `5`) |
| `stage2/` | supplementary Simar–Wilson (2007) second-stage check on DEA scores (40 replicates, planted driver z1 and placebo z2) | `python sw_stage2.py 0 40 1 0` (env B1/B2), `python agg_sw.py` |
| `review_override/` | supplementary human-review break-even analysis and override-log reconstruction/tamper test | `python reviewer_sensitivity.py linear 20; python agg_rs.py; python audit_log_test.py 20` |
| `h9/` | drift-fallback rule (tuning on separate seeds, evaluation, DOSM) | `python run_h9.py tune .` then `eval .`; `python agg_h9.py`; `python h9_real.py` |
| `explain/` | explanation-fidelity test (H10, exploratory) | `python explain_test.py .` then `python agg_explain.py` |
| `baselines/` | stronger baselines (20 replicates per scenario) | `python run_baselines.py SCENARIO .` (env R0/R1/STEP/OFF), `python agg_baselines.py` |
| notebook | `IMCOM2027_Paper1_Results_Check.ipynb` re-runs the DOSM pilot, checks it against stored results, and plots every study | `jupyter notebook` |

Scripts that import `run_experiment_prospective.py` expect it in the same folder (a copy is included where needed).

## Data
- Department of Statistics Malaysia (DOSM), OpenDOSM, *Quarterly productivity by economic sector* (`productivity_qtr`) and *Annual productivity by state* (`productivity_state`), licensed CC BY 4.0, via https://open.dosm.gov.my/ . Files here are unmodified or reshaped copies; please cite DOSM.
- All other data are synthetic and generated by the scripts.

## Notes
- The synthetic results concern processes specified by the author; the real-data checks are plausibility checks on aggregate series, not tests on organizational units.
- H10 (explanation fidelity) was added after the other hypotheses had been evaluated and is exploratory.
